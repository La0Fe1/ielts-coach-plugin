# IELTS 口语教练 v1.6.0

这一版让「全真模考」真正跑起来，并把手感往 90 分推了一把。

## 全真模考能走完了

- Part 1 → Part 2 → Part 3 自动切换，Part 2 会整段念 cue card（You should say 四个要点）。
- 题单问完后，考官说结束语，界面出现「结束本课并出报告」。
- MCP 模式下也不再强行把所有题标成 part1。

## 考官先开口，批改随后到

- 模型流式输出，第一句一出现就开始合成语音并推送，不再等整段 JSON。
- 实测每轮 4.8–7.5 秒（原来 6.5–7.1 秒，首句更早出声）。

## 报告页能连刷错词了

- 「▶ 连刷本课错词」：一个词一个词跟读，≥75 分自动进入下一个。

## 修了 4 个 Bug

1. 手动模式下轻按空格无法停止录音（现在短按切换、长按松开发送都正常）。
2. 探测拿到的 `probe_id` 没传回提交接口，同一段录音被识别两次。
3. 切换课程会擦掉 `?embed=1`，侧栏里打开会丢标记。
4. 模型下载没有进度，现在每 1.5 秒轮询、可选三种 Whisper 模型。

## 一个安全细节

只有设置 `IELTS_COACH_DEBUG=1` 时才开 9222 调试端口。
