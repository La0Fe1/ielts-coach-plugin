# IELTS 口语教练 v1.4.0 — 中英都能说

**插件负责「实时听、实时判断、题库、评分、记忆」；能力上限由你 agent 里的基底模型决定。**

## 这次新增：中文语音

以前麦克风只认英文，你说中文会被转成乱七八糟的英文。现在 ASR 自动识别语言：

| 你说 | 转写 | 系统反应 |
| :--- | :--- | :--- |
| I live near the coast. | 英文，完整 | 自动进下一题 |
| 结束。 | 中文，`intent=end_lesson` | 结束本课、出报告 |
| 这个词怎么用？ | 中文 | 交给 agent 用中文回答，不计发音分 |

细节：

- 语言自动识别；长英文答句如果被误判，会自动按英文重跑一次，保证答案不被破坏。
- 中文回合**跳过英文音素评分**（那本来就不适用），并带上 `language` 与 `intent` 字段。
- 停止口令中英都认：stop / that's all / I'm done / 结束 / 下课 / 不练了 / 拜拜。
- 便携包内的识别模型从 `small.en` 换成多语言 `small`（体积一样）。

## 顺手修的一个严重 bug

便携版的 ASR 之前**根本加载不到包内模型**（`download_root` 指向了用户目录，离线时找不到快照）。
也就是说 v1.2/v1.3 的便携包，语音识别实际是坏的——我用便携包自己的解释器跑了一次才暴露出来。
现在已修复，并在便携解释器里实测：`這個單詞怎麼說?` → `language=zh`。

## 下载（机器上不需要 Python）

1. 下这三个文件到同一文件夹：`IELTS-Coach-full.zip.001`、`.002`、`merge-and-extract.bat`
2. 双击 `merge-and-extract.bat`
3. 双击 `连接我的AI工具.bat`
4. 打开你的 AI 工具，说「开始练雅思 Part 1」

## 从 v1.3 升级

覆盖安装目录即可；记忆在 `%USERPROFILE%\.ielts-coach`，不受影响。

## 已知限制

- 便携版只有 Windows x64
- 完整版 3.3 GB，分两卷（GitHub 单文件上限 2 GB）
- 中文只用于提问/指令，雅思作答仍用英文评分
