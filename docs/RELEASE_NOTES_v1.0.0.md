# IELTS 口语教练 v1.0.0

在你常用的开发工具（dsh / Cursor / VS Code / Claude Code）里说一句「开始上课」，
弹出一个独立的桌面窗口陪你练雅思口语。语音模型与题库全部内置，离线可用。

## 下载

### 完整版（推荐，识别最准）
下载这三个文件，放在**同一个文件夹**：

- `IELTS-Coach-full.zip.001`（1800 MB）
- `IELTS-Coach-full.zip.002`（539 MB）
- `合并并解压.bat`

双击 `合并并解压.bat`（用 Windows 自带的 tar，不需要装 7-Zip），
然后双击 `启动口语教练.bat`。

### 轻量版（一个文件）
- `IELTS-Coach-portable-win64.zip`（1379 MB）：解压即用，识别模型 small.en。

### 分体版（适合网速不稳）
- `IELTS-Coach-app.zip`（623 MB）
- `IELTS-Coach-models-large.zip`（1658 MB）
两个都解压到同一文件夹，效果同完整版。

## 特性

- 桌面窗口（WebView2 原生窗口，不是浏览器标签页），单实例，可独立于编辑器运行
- 题目由本地题库随机抽取（162 题），第 2 节课起自动复习上次的错题与弱音素
- 音素级发音评分（GOP，int8 量化，与 fp32 的 CTC top-1 一致率 1.0000）
- 中英双语：考官说英文，讲解用中文，语音按句子自动切换音色
- 卡壳识别：停顿 2 秒给提示词，2.6 秒自动接话
- 长期记忆存在 `~/.ielts-coach`，换工具、换窗口都能读到

## 需要

- Windows 10/11 x64（WebView2 自带）
- 机器上**不需要**安装 Python
- 想获得语法纠错：在 dsh / Cursor / Claude Code 里说「开始上课」，
  由你本地开发工具里的大模型当老师（消耗你自己的 token）

## 隐私

音频只发往 `127.0.0.1:8765`，不上传任何服务器。
