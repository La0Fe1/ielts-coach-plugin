# IELTS 口语教练 v1.5.0

现在不用配 AI 工具了。设置里填一个 DeepSeek key，双击窗口就能上课。

## 变简单了

- 独立模式：出题、纠错、评分全用你填的模型，不再需要 Cursor / 豆包 / dsh。
- 也能接任意 OpenAI 兼容接口，或者本机 Ollama。
- 不想填 key：继续用原来的 MCP 模式，接你自己的 agent。

## 变准了

- 断句：短句停 2.6 秒才提交，长句 1.5 秒，不再抢话。
- 中文也能说：中文提问会转写成中文并用中文答；说「结束」就下课。
- 跟读重测：点标红的词，跟着读一遍，按那个词本身打分。

## 变快了

- 每轮返回给模型的 token 从 2,958 降到 488。
- 说完到提交 540ms → 347ms。

## 新界面

双栏工作台：左边对话，右边教练面板；设置里可以调发音、语速、模型。

## 下载

1. 下 `IELTS-Coach-full.zip.001`、`.002`、`merge-and-extract.bat` 到同一文件夹
2. 双击 `merge-and-extract.bat`
3. 双击 `启动口语教练.bat`
4. 设置 → 填 DeepSeek key → 测试连接 → 开始上课

## 从 v1.4 升级

覆盖安装目录，记忆在 `%USERPROFILE%\.ielts-coach`，不受影响。
