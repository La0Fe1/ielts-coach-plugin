# IELTS 口语教练 v1.5.2

修了 6 个会影响正常使用的 Bug，补了 5 项体验。

## 修掉的

1. 桌面窗口里点「开始上课」后，2 秒内不会被自己刷回开屏页（URL 会同步 `?session=`，壳只在页面确实不一致时才重载）。
2. 直连模式的语法错题字段对齐数据库，错题本和记忆不再全是空值（兼容模型输出的 `type/wrong/right`）。
3. 直连模式记住前 6 轮对话；中文提问不消耗题库；说「结束」立即下课并出报告；课后把薄弱点写进长期记忆。
4. 模型失败不再无提示干等：推送错误到界面，带「去设置 / 重试」；首题改为极简模板，**首题等待从 6 秒降到 0.5 秒内**。
5. 设置里的语速真正生效（Edge-TTS 按 `+/-N%` 合成，缓存键含语速）。
6. 单词跟读最小 0.5 秒、整句 1.5 秒，不再逼你干等 2 秒。

## 补充的

- 自由模式停顿 1.4 秒只探一次句法：没说完自动把静默延长到 3.5 秒。
- 录音中可点「重说」；手动模式长按空格说话、松开即发送。
- 发音抽屉内置中国考生易错音的中文口诀 + 最小对立词（think / sink），点词就能听。
- 设置里能看到本机模型状态，缺模型可按需下载。
- 记忆抽屉可直接「针对薄弱点开专项课」；报告显示平均语速、总开口时长、停顿次数。
