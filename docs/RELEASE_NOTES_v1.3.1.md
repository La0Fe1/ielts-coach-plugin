# IELTS 口语教练 v1.3.1 — 更省 token，更快接话

**插件负责「实时听、实时判断、题库、评分、记忆」；能力上限由你 agent 里的基底模型决定。**

## 这次只做两件优化

### 1. 每轮返回的 token 降低 83.5%

给 agent 的发音结果只保留「需要关注的词」：

| | 之前 | 现在 |
| :--- | ---: | ---: |
| 单轮 payload | 2,958 token | **488 token** |
| 内容 | 每个词的逐音素轨迹 | 总分 + 标红/标黄词 + 音素问题 + 弱音素 |

完整音素明细仍在桌面窗口里，agent 只在需要时看结论。
按一节课 5 题算，大约省下 **1.2 万 token**。

### 2. 说完到提交快 190 毫秒

停顿探针已经把这句转写过一次，正式提交时直接复用（音频长度差 ≤1.8 秒时命中），
省掉一次 ASR。实测：540 ms → **347 ms**。

## 句子完整度判断（v1.3.0 起）

| 你说的 | 判定 | 行为 |
| :--- | :--- | :--- |
| I live in a small city near the coast. | 完整 | 自动进下一题 |
| I live in a small city near the | 停在介词 | 继续听 |
| I like it because | 停在连词 | 继续听 |
| 上面任一 + 再静默 2 秒 | 卡壳 | 弹 2–3 个提示词 |

## 下载（机器上不需要 Python）

1. 下这三个文件到同一文件夹：`IELTS-Coach-full.zip.001`、`.002`、`merge-and-extract.bat`
2. 双击 `merge-and-extract.bat`
3. 双击 `连接我的AI工具.bat`
4. 打开你的 AI 工具，说「开始练雅思 Part 1」

## 从 v1.3.0 升级

覆盖安装目录即可；记忆在 `%USERPROFILE%\.ielts-coach`，不受影响。
