# IELTS 口语教练 v2.0.1

修掉真实 Key 联调会直接翻车的问题，并把「假按钮」补成真功能。

## 修复

- **开场白不再丢**：等上游握手完成才发开场指令，慢网络下第一题也会出声。
- **自带 Key 能用精批和报告**：/api/coach/* 接收浏览器的 Key；没有凭证就返回错误，**不再伪造 6.0 分报告**。
- **服务端 Key 不再裸奔**：配了 Key 但没设 ACCESS_CODE 时，默认拒绝他人使用（可用 ALLOW_PUBLIC_HOST_KEY=true 显式公开）。
- **Gemini 字幕顺序正确**：先落盘你的话，再出考官字幕；不再中途发非法帧导致断连。
- **切耳机/外放、断线提示**立即生效（不再读到旧闭包）。
- **外放尾音不再被反录**：等最后一段音频播完 220ms 才解麦。
- **选 Part 2 直接开课**会立刻弹题卡 + 60 秒准备。

## 新增

- 历史课与长期记忆抽屉：回看字幕/报告、导出导入学习档案；开课自动带最近 5 条记忆。
- 盲听点单条字幕可偷看；点任意回答查看那一轮精批。
- 服务端 1.2 秒没给字幕时，用浏览器识别显示浅色草稿。
- 设置分「自带 API Key / 访问口令」两个 Tab，可选模型、Workspace ID、精批专用 Key，并能「测试连接」。
