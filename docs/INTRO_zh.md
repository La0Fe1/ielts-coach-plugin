# 我们做了什么（大白话版）

## 一句话

一个装在自己电脑上的雅思口语陪练：打开一个独立小窗口，跟它说英语，它当场指出你哪个词发音不对、哪句话语法错了，并把你的弱项记下来，下节课接着练。

## 用起来是这样

1. 在 dsh / Cursor / VS Code / Claude Code 里说一句「开始上课」。
2. 桌面弹出一个窗口（不是浏览器标签页），点一次「开始语音连麦上课」，允许麦克风。
3. 考官用英文提问。你答完，点一下「我说完了」，它接下一题；说到一半卡住了，它会先给你 2–3 个提示词。
4. 每答完一题，下面立刻出现中文批改：哪句说错了、怎么说更地道、哪个词发音有问题。
5. 说「结束本课」，出一份四维报告：流利度 / 词汇 / 语法 / 发音。
6. 下次上课，它先复习你上次错的点，再出新题。

## 你说完一句话，后面实际发生了什么

- 你的声音在本机转成文字，约半秒。
- 同时做发音评分：把每个词拆成音素，和标准发音逐段比对，标成绿 / 黄 / 红。
- 停顿超过 2 秒，它判断你卡壳了，弹出 2–3 个候选词（点一下能听发音）。
- 批改由你本机开发工具里那个大模型完成——它当老师，用你已经付费的额度。
- 错题、弱音素、Part 2 素材写进本机数据库；下节课的出题计划先读这份记忆。

## 三块分工（说人话）

1. **脑子** = 你已经在用的 AI（dsh / Cursor 里的大模型）。它出题、批改、追问，消耗你的 token，不用另外订阅。
2. **耳朵和嘴** = 装在你电脑里的语音模型。断句、转写、发音评分、朗读全在本机，不上传。
3. **记性** = 一个本地数据库（`~/.ielts-coach`）。换工具、换窗口、换电脑上的账号都读同一份。

安装包里没有大模型，所以不需要显卡跑 LLM；但识别、评分、合成、题库全在包里，装完不联网也能练。

## 和同类产品比

| 对比对象 | 它们做的事 | 我们不一样在哪 |
| :--- | :--- | :--- |
| 云端口语 App（ELSA、Speak、流利说、有道口语等） | 手机 App、订阅制，录音上传云端，用它们的模型打分 | 我们全在本机：音频不出机器、不订阅、可断网；发音给到音素级，不是一个总分 |
| 雅思题库 App（雅思哥、小站等） | 题库 + 录播课 + 真人批改 | 我们是实时对话，不是刷题；每节课按你的错题自动换题和复习 |
| 通用语音助手（ChatGPT 语音、豆包） | 什么都能聊 | 它们不做逐音素发音评分，没有 Part 1/2/3 的考试结构，也不按你的弱项安排下节课 |
| 编辑器里的 AI（Cursor、Copilot） | 只帮你写代码 | 我们不重新造大脑，直接借它当老师 |
| 本地模型工具（Ollama、LM Studio） | 给你一个跑模型的壳 | 我们给的是完整教学流程 + 语音栈 + 长期记忆 |

**完全同类的产品目前没有。** 把「开发者工具里的大模型当老师」＋「本地语音模型做耳朵」＋「音素级发音评分」＋「跨课记忆自动复习」拼在一起，还做成双击就能装的桌面窗口，市面上没有现成的。

（各家功能会更新，上表只说结构性差异，不比较具体价格和版本。）

## 它不是什么

- 不是网页。主入口是桌面窗口，关掉编辑器它还在。
- 不替你练。它只负责提问、听、纠错、记录。
- 不送大模型。智力来自你已有的 AI 工具，会花它的 token。
- 目前只支持英文口语，便携版只做 Windows x64。
