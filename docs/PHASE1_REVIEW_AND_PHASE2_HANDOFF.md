## 三、用户核心反馈：前端必须改版为“连麦式即时问答交互”

原 Phase 1 界面像“左边控制台手动点按录音 + 右边空白等待列表”的语音识别输入工具，且开局出现“浏览器阻止自动播放”黄字，不符合即时问答口语陪练体验。请按以下要求重构 `web_src/`：

1. **一键连麦授权（彻底消除自动播放提示）**：
   - 进入页面时给出醒目的 **`🎙️ 开始语音连麦上课`** 入口按钮。用户点击这一次后，同时解锁浏览器 `AudioContext` 自动播放权限和麦克风权限，之后全程不再出现“浏览器阻止了自动播放”提示。
2. **默认全自动轮替接话（Hands-free + Silero VAD）**：
   - 考官 TTS 播报完毕后，麦克风**自动开启收音**，底部状态球提示“正在听你说…”。
   - 用户说完自然停顿（约 `1.8s`，由 `silero-vad` 判定）自动切段提交，无需每轮都手动点开始和停止（保留底部小开关可切回手动按键模式）。
3. **居中对话气泡流布局（替代左控台 + 右表单）**：
   - 主视口改为类似聊天/通话的**居中问答流**：左气泡为考官（语音播放波纹 + 重听），右气泡为学习者（提交后秒出你的转写气泡，不再干等“等待学习者回答...”）。
   - 即时纠错（亮点表扬 + 语法改错 + 7.5+ 地道升级 + 单词红黄绿发音标注）以**紧凑可展开卡片**的形式直接附着在对应学习者气泡下方。
   - 底部固定极简 **Live Voice Dock**：实时声波状态球、暂停/静音、重说上一句、切换自动/手动模式、`结束本课并生成报告`。
